Make notification keys

This makes the two keys that let your checker send notifications to your devices. It happens inside your browser, nothing is sent anywhere. Do this only once. Making new keys later makes the old ones stop working.

On GitHub: your repo → Settings → Secrets and variables → Actions → New repository secret. Name: VAPID_PRIVATE_KEY. Secret: paste this key. Save.

It is also saved in the file vapid.json that just downloaded. Upload that file to your repo (Add file → Upload files).

When both are done, open your page → menu → Notification settings.
